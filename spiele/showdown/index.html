So läuft ein Duell
  1. Beide öffnen diese Seite. Einen Code gibt es nicht.
  2. Jeder wählt eine Waffe und tippt auf Bereit.
  3. Sobald beide bereit sind, startet die Musik. Sie endet nach einer Zufallszeit, dann blitzt der Bildschirm.
  4. Wer nach dem Ende zuerst tippt, gewinnt.
